# Persefoni Connector — Preparation

**Category:** C48. Environmental, Social & Governance (ESG) Reporting  
**Preparation status:** Complete Primary Specification  
**Architecture Policy:** Vendor-specific REST/API Integration (Scaffold Mismatch Cleared)

## 1. Паспорт приложения
- **Название:** Persefoni Connector (`persefoni-connector`)
- **Официальный ресурс:** https://www.persefoni.com
- **Базовый API:** `https://api.persefoni.com/v1`
- **Назначение:** Полнофункциональная интеграция платформы Imperal Cloud с Persefoni для решения задач предметной области: углеродный учет по стандарту GHG Protocol, расчет финансируемых выбросов (PCAF) для финансового сектора и комплаенс CSRD/SEC.

## 2. Решаемая проблема
Углеродный учет по стандарту ghg protocol, расчет финансируемых выбросов (pcaf) для финансового сектора и комплаенс csrd/sec. В настоящее время операторам и ответственным лицам приходится вручную переключаться между системами, дублировать операции и терять целостность аудита. Коннектор предоставляет автоматизированный и надежный шлюз.

## 3. Пользователи, роли и права доступа
- **Ключевые роли:** риск-менеджер банка, специалист по нефинансовой отчетности, комплаенс-контролер.
- **Разделение прав:** Доступ только к тем данным и функциям, которые разрешены выданным токеном/учетной записью вендора.

## 4. Ключевые сущности
учетные транзакции (/activities), расчетные углеродные эквиваленты (/footprints), портфельные компании, аудиторские срезы.

## 5. Первичный сценарий
`загрузка финансовой активности -> автоматический расчет выбросов Scopes 1-3 -> формирование отчета для регулятора`.

## 6. Границы и ограничения безопасности
- Использование принципа BYOC (Bring Your Own Credentials).
- Никаких захардкоженных секретов. Все токены хранятся в защищенном хранилище платформы.
- Деструктивные и финансовые действия требуют обязательного подтверждения оператором.
